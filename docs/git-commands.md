\# Git Commands Reference



\## Repository Setup



\* `git init` — Initialize a repository.

\* `git status` — Check the working tree.



\## Branch Management



\* `git branch` — List branches.

\* `git switch -c branch-name` — Create and switch to a branch.

\* `git switch branch-name` — Switch branches.



\## Tracking and Commits



\* `git add .` — Stage changes.

\* `git commit -m "message"` — Create a commit.



\## Remote Repository



\* `git remote -v` — View remote repositories.

\* `git push` — Push commits.

\* `git pull` — Fetch and integrate changes.



\## Collaboration



\* Pull requests allow changes to be reviewed before merging.

\* Merge conflicts occur when changes cannot be combined automatically.



\## Versioning



\* `git tag v1.0.0` — Create a version tag.

\* `git tag` — List tags.
